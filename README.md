
# Program Rekap Nilai Rapor Siswa Yayasan Sekolah Purwadhika BSD CITY
Sistem sederhana Create, Read, Update, Delete (CRUD) pada data nilai siswa jenjang SD, SMP, SMA menggunakan bahasa pemrograman python
## 1. Problem Statement 

Proses pengolahan nilai rapor siswa di banyak sekolah masih dilakukan secara konvensional menggunakan perhitungan manual atau aplikasi spreadsheet sederhana. Cara tersebut memerlukan waktu yang cukup lama, terutama ketika guru harus mengolah nilai banyak siswa sekaligus. Selain itu, proses perhitungan nilai akhir masih rentan terhadap human error, seperti kesalahan input data maupun kesalahan perhitungan. Oleh karena itu, diperlukan sebuah sistem berbasis teknologi informasi yang dapat membantu guru mengelola data nilai secara lebih cepat, akurat, dan terstruktur sehingga proses pembuatan rapor menjadi lebih efisien serta meminimalkan risiko kesalahan.


## 2. Features
### A. Main Menu

### B. Submenu
A. Create input data siswa

B. Read semua data siswa yang sudah diinputkan

C. Update data yang sudah diinputkan

D. Delete data siswa

E. Statistika Nilai siswa dari keseluruhan data yang diinput

## 3. Scope of Problem: 
1. Fitur update memuat update semua isi parameter dalam 1 row (tidak bisa hanya mengganti 1 kolom)
2. Fitur delete itu menghapus 1 row (tidak bisa 1 kolom saja dalam row terpilih)
3. Fitur statistik itu mengakumulasi nilai keseluruhan input data (belum bisa per kelas)
4. Input nilai hanya bersifat angka bulat
