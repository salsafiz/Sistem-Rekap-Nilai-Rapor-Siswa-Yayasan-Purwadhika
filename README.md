# Sistem-Rekap-Nilai-Rapor-Siswa-Yayasan-Purwadhika
Sistem pengelolaan nilai rapor siswa berbasis Python yang memudahkan guru dalam menginput, mengubah, menghapus, dan melihat data nilai siswa (CRUD System). Sistem juga menghitung nilai akhir, predikat, status kelulusan, serta menampilkan statistik nilai secara otomatis berdasarkan jenjang pendidikan yakni SD, SMP, dan SMA.
